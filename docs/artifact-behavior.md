# Artifact collection and public decision explanations

Scripted agents previously dropped a find on their very next decision, which made collection difficult to see. They also omitted motivation from their decision records and could permanently discard a target after one failed approach. Model motivations existed but were not carried through into authoritative actions and their timeline events.

The research goal is now to collect portable artifacts, study and activate them while carrying, transport them, and deliberately display them elsewhere. Scripted agents prioritize a free portable artifact over ordinary rocks. They approach first if necessary, pick up without an unnecessary pre-inspection, inspect and activate while holding the find, transport it at least 12 m, and keep it for at least 20 simulation seconds before choosing a clear nearby placement. They remember their own placed finds to avoid pickup/drop loops. A failed approach defers a target for 200 ticks and permits later retry. If a chosen find disappears from view after walking, the agent looks toward its last observed location once before abandoning that attempt. Immovable artifacts are studied in place. Codex receives the same goal as guidance; model behavior remains autonomous.

Each visible object now includes factual pickup eligibility, the current blocker (distance, ownership, capacity or immovability), and interaction distance. Carried artifacts belonging to other agents are visible under the normal field-of-view, range and occlusion rules, so ownership can inform a decision. The World Engine still validates execution independently, including competing pickups and changed circumstances.

A proposal can include a short public motivation and up to eight artifact assessments: object ID, collect/approach/keep/defer/leave/inspect/place, and a concise reason. These are agent-authored decision summaries, not hidden chain-of-thought or guarantees of success. Scripted summaries reflect explicit policy rules; Codex supplies its own summaries. Both propagate through the scheduler into decisions, accepted actions, result events, SQLite and replay. Fallback waits have an explicit runtime explanation. Older records remain readable and are labelled when no motivation was recorded.

Live shows current proposed/running actions, per-candidate assessments, and distinct success/failure outcomes with readable validation errors. Agent cards show the active motivation and named carried objects. Decisions refresh every two seconds while Live is visible; expanded or focused details are left alone during automatic refresh. Timeline and Replay show the persisted explanations alongside their existing source inspector. The decision API accepts `?limit=12` for the live view (1–100 entries), while the default history response stays unchanged.

The Codex structured response requires `artifactConsiderations`, using an empty array when appropriate. This follows the requirement that every declared output property be required in a strict schema. See [official OpenAI Structured Outputs documentation](https://developers.openai.com/api/docs/guides/structured-outputs). Internal action metadata and MCP inputs retain optional assessments for compatibility with existing policies and direct tool callers.

Validation: typecheck, production build and 79 tests pass. New regressions cover pickup/study/transport/placement, minimum carry duration, avoiding repeated pickups, range, retry cooldowns, visible ownership, immovability, capacity, metadata propagation into durable decisions/events/replay, MCP metadata separation, and Codex output-schema requirements. Browser verification observed Alpha carrying a Golden shell and Beta carrying an Ancient relic, with live intent, failure feedback, ownership explanations and automatic decision summaries.

A bounded real-model check is available as `npm run verify:artifact`. It gives one Codex agent a visible, free portable crystal within pickup range; the other inhabitants wait. At most four model decision attempts and 90 seconds are allowed. It requires an autonomous successful pickup, an explicit public pickup assessment, and matching motivation on the world action. The result is written to [the live test report](artifact-pickup-live-result.json). The real Codex check passed: its first decision picked up the crystal successfully and explained that it was portable, unowned, within range, and that carrying capacity was free.
